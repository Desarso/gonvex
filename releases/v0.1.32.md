## Summary
- Offline mutations are now safe end-to-end for React Native consumers: the client outbox accepts injectable durable storage, and the server deduplicates mutation replays by idempotency key.
- New KV-backed store factories let an app bind one small key-value adapter (for example over expo-sqlite) and get durable query-cache, sync, and outbox persistence on platforms without IndexedDB.
- Runtime reliability work: unified query admission, reconnect-safe worker recycling, shared project bundles across aliases, and Postgres-persisted scheduled jobs.

## Changes
- `@gonvex/client` adds an `OutboxStore` interface and `StoreMutationOutbox`: the same totally ordered queue engine as the Dexie outbox (auto-increment ordering, per-entity causal barriers, inflight recovery, stable idempotency keys) with write-through persistence to an injected store. Configure it via `outbox.store` in `GonvexClientOptions`. A failing store degrades to in-memory queue semantics for the session.
- New `kv-stores` module in `@gonvex/client`: `GonvexKv`, `createKvQueryCacheStore`, `createKvSyncStore`, `createKvOutboxStore`, and `createMemoryGonvexKv`, upstreamed from the Whagons React Native app with its table names and key format preserved so existing on-device data stays readable.
- `mutation.call` now carries an explicit `idempotencyKey` (`@gonvex/protocol`), and the server records applied keys so an outbox replay after reconnect returns the original result instead of committing the write twice.
- Query admission is unified with reconnect-safe worker recycling, and project bundles are shared across aliases to cut duplicate compilation.
- Scheduled jobs persist in Postgres, cron runs are staggered per tenant, and writes invalidate precisely.
- Deployment: production promotion is gated behind a protected lane, and runtime compiler state lives outside the data volume.

## Technical Notes
- All five npm packages (`@gonvex/protocol`, `@gonvex/client`, `@gonvex/react`, `@gonvex/cli`, `create-gonvex`) release in lockstep at 0.1.32.
- Server operators should deploy the Go runtime alongside this client release to activate mutation idempotency dedupe; older servers still accept the new client but replay dedupe only happens server-side.
- Two Linux-only tests (worker RSS measurement, load-generator host-memory reserve) now skip on other platforms instead of failing; both read `/proc`.
