## Summary
- Prevent warm query reloads from degrading to full server payloads during brief IndexedDB contention
- Added configurable timeout option for reading persisted cache entries
- All packages updated to v0.1.17

## Changes
- **Improved Delta-Only Revalidation**: Increased the default wait time for persisted query cache reads from 50ms to 250ms. This ensures that temporary IndexedDB contention during startup does not cause warm queries to fall back to expensive full-server payloads instead of efficient delta revalidation.
- **Configurable Cache Read Timeout**: Added `readTimeoutMs` option to `QueryCacheOptions` for customizing how long the client waits for cached query results before subscribing without a cache revision.

## Technical Notes
- `@gonvex/client`: New `readTimeoutMs` property in `QueryCacheOptions` with JSDoc documentation; invalid values fall back to the new default of 250ms (`defaultQueryCacheReadTimeoutMs`)
- Monorepo version bump to v0.1.17 across `@gonvex/client`, `@gonvex/react`, `@gonvex/protocol`, `@gonvex/cli`, and `create-gonvex` packages
