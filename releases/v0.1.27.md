## Summary
- **Eliminate sync subscription fan-out**: Server now filters change notifications by affected tables and coalesces updates, reducing frame volume from O(subscriptions) to O(changed collections) per revision.
- **Support video streaming**: Storage proxy correctly handles HTTP range requests (206 Partial Content) for video and audio assets.
- **Custom domain routing**: Runtime can route public HTTP hosts to specific projects via the new `GONVEX_PROJECT_HOSTS` configuration.

## Changes
- **Sync Performance**: Subscriptions only receive `sync.ready` frames when their tables change. Unchanged subscriptions advance via a new connection-level `sync.watermark` frame without hashing or listener emission. The client reuses verified integrity digests when row arrays are identity-unchanged, cutting CPU use on large tenants.
- **Storage Proxy**: Forwards `Range` request headers to the underlying S3-compatible store and preserves `Accept-Ranges`, `Content-Range`, and `Content-Length` headers in 206 responses.
- **Runtime Routing**: Anonymous registered HTTP functions can now be served from custom domains by setting `GONVEX_PROJECT_HOSTS={"share.example.com":"app"}`.

## Technical Notes
- **Protocol**: Added `sync.watermark` frame and capability negotiation (`syncReadyMany`, `syncWatermark`). Client advertises capabilities in the `auth` message; server emits `sync.readyMany` batched frames when supported.
- **Schema**: Bumped `NotifySchemaVersion` to "5". The `gonvex_sync_finalize_transaction` trigger now aggregates `DISTINCT table_name` into the `pg_notify` payload (with 7KB fallback).
- **npm Packages**: All packages (`@gonvex/client`, `@gonvex/protocol`, `@gonvex/react`, `create-gonvex`, `@gonvex/cli`) bumped to 0.1.27.
- **Server**: Per-connection 15ms ready coalescer; `notifySyncRevision` filters by changed tables and shares one clock read per notification. Cursor-only watermark persists are throttled to 1/s per collection.
- **Client**: New `sync-watermark.test.ts` coverage; `integrityEpoch` guards digest reuse across epoch changes.
