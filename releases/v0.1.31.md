## Summary

- Added one durable entity-level optimistic state layer for sync and query subscriptions
- Made generated Gonvex metadata drive immediate React signal updates without app-owned cache patches
- Hardened mutation durability, rollback, authenticated outbox isolation, and authoritative reconciliation

## Changes

- Added Go builders and generated function-reference metadata for optimistic mutations and projections
- Projected pending entity patches into top-level arrays, paginated results, and single-object queries
- Preserved mutation IDs through query and sync protocol messages so every source can acknowledge the same write
- Kept accepted overlays visible across stale snapshots, reloads, and fast-RPC/slow-subscription races
- Added durable offline queuing for mutations with or without optimistic UI metadata
- Routed optimistic `mutationMany` calls through the same standard mutation path

## Reliability and security

- Scoped durable outbox rows by deployment, project, tenant, and authenticated identity
- Prevented opaque credentials from restoring another session's pending mutations
- Made outbox transitions transactional and safe across acknowledgements, auth switches, and concurrent cleanup
- Removed legacy unscoped outbox rows whose owner cannot be proven

## Compatibility

- Existing collection-style explicit patches remain supported through the `collection` alias
- Applications opt into generated behavior by declaring optimistic mutation/projection metadata
