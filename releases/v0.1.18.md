## Summary

- Adds configurable bounded retention for listenerless live queries.
- Lets local-first applications switch back to recently visited routes without WebSocket unsubscribe/subscribe churn.

## Changes

- `GonvexClientOptions.querySubscriptionRetentionMs` controls how long a live query remains subscribed after its final listener unmounts.
- Reattaching during the retention window reuses the same server subscription and immediately replays its latest result.
- The default remains 250 ms for backward compatibility; configured values are bounded to five minutes.
- Abandoned subscriptions still release deterministically at the end of the retention window.

## Technical Notes

- Added timer-driven tests for reuse, replay, and eventual unsubscribe behavior.
