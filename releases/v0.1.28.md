## Summary
- **Sub-200ms certified reactive updates at 1000 users**: 38-iteration optimization achieves 182ms p95 TTLU (time to last user) for 1,700 connections and ~149k subscriptions, down from ~80s baseline at 250 users
- **New load testing with TTLU measurement**: `gonvex-load` now replays realistic Whagons user profiles and measures end-to-end update propagation latency from commit to browser receipt
- **Dashboard data editing**: Click any row in the data browser to edit values with type-preserving validation (JSON for objects/arrays, strict types for primitives)
- **Ephemeral state API**: New `ctx.Ephemeral` for tenant-scoped, TTL-bound JSON storage in Valkey—bypasses durable cache and Postgres transactions when appropriate

## Changes
- **Reactive performance**: Immediate committed invalidation replaces 75ms debounce; visibility-fingerprint execution sharing; capability-gated delta transport; per-connection query fanout; precise no-ops for unchanged results
- **Subscription delivery**: Table-filtered invalidation using Postgres trigger precision; 150ms burst cooldown; bounded rerun dispatcher (32 workers); subscription skip metrics
- **Metrics & observability**: 30s load history ring (3h retention); update propagation latency tracking (TTLU p50/p95/max); new dashboard charts for propagation time and connected load
- **Dashboard improvements**: Grouped tenant cron registrations with scope disclosure; per-client resource usage display; editable data rows with type-aware inputs
- **Build reliability**: Disabled VCS stamping for project plugin builds to prevent git exit 128 failures in cache directories
- **CI/CD**: Main branch deploys only to dev runtime; production promotion gated by Monitor verification

## Technical Notes
- **Required**: `VALKEY_URL` (or `REDIS_URL`) is now mandatory—runtime exits on startup if unset or unreachable
- **Protocol**: Delta transport supports keyed array/page patches, order deltas, atomic object patches; legacy clients receive full results; revision mismatch triggers full resync
- **Load runner**: Profile v2 schema with users, connections-per-user, pools, subscription distribution, and mutation mixes; bundled `whagons-1000-users.json` and `whagons-prod-2026-08-11.json` profiles
