# Gonvex 0.1.15

## Durable sync reliability

- Serialize snapshot, delta, reset, and IndexedDB persistence so slow local writes cannot corrupt a newer cursor.
- Retry transient sync delivery errors with bounded exponential backoff.
- Coalesce notification storms into one active and one pending delivery pass.
- Recover missed durable revisions after PostgreSQL listener reconnects.
- Bound sync database work and WebSocket writes with timeouts.
- Avoid an authentication-revocation deadlock during active sync delivery.

## Verification

- Added adversarial client and server tests for slow storage, transient failures, 10,000-event storms, auth revocation, transaction rollback, ordered mutations, and 256 concurrent writers.
