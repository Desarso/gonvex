# Quickstart

Start the reference stack in a separate terminal:

```bash
git clone https://github.com/Whagons-International/gonvex.git
cd gonvex
make stack
```

Create a Vite React app:

```bash
npm create gonvex@latest my-app -- --template vite-react
cd my-app
npm install
npm run dev
```

The initializer creates TypeScript modules and versioned SQL migrations:

```txt
my-app/
  src/
  gonvex/
    index.ts
    messages.ts
    _generated/
  migrations/
    0001_messages.sql
  package.json
  gonvex.json
```

`gonvex dev` watches the module and migration folders, extracts the manifest,
bundles the TypeScript module for the V8 host, applies migrations, regenerates
bindings, and optionally runs the frontend command after `--`.

## Define a module

```ts
import { reducer, schema } from "@gonvex/module-sdk";

export const create = reducer({
  args: schema.object({ id: schema.id("tasks"), title: schema.string() }),
  result: schema.object({ id: schema.id("tasks"), title: schema.string() }),
  offline: { mode: "allowed", conflict: "expectedVersion" },
  optimistic: {
    effects: [{ operation: "upsert", entity: "tasks", id: ["id"], value: {
      id: { $arg: "id" }, title: { $arg: "title" },
    } }],
  },
  run: ({ db }, task) => db.insert("tasks", task),
});
```

Queries are read-only. Reducers are the only normal durable write path. Actions
perform external work and call a Reducer when they need to change application
state. Use a Replica Collection for bounded local entities and a structured
Live Query for large indexed windows.

## Use generated bindings

```tsx
import { api } from "./gonvex/_generated/api";
import { useQuery, useReducer } from "./gonvex/_generated/react";

export function Tasks() {
  const tasks = useQuery(api.tasks.list, { status: "open" });
  const createTask = useReducer(api.tasks.create);
  return <TaskList tasks={tasks ?? []} onCreate={createTask} />;
}
```

## Connect a runtime project

```bash
npx gonvex login
npx gonvex project create my-product --database-mode multiTenant
npx gonvex auth tenants create "Acme" --owner owner@acme.example
```

The CLI writes the project ID, runtime URL, and project key to `.env.local`.
Keep the project key server-side; only `VITE_` variables belong in the browser.
