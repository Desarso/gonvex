---
title: Replica Collections and Local Replica
description: Bounded persistent collections, atomic transactions, and offline completeness.
---

A Replica Collection keeps a bounded, authorized entity set in the Gonvex
Local Replica.

```go
app.ReplicaCollection(
  "tasks.recent",
  RecentTasks,
  gonvex.ReplicaTable("tasks").
    Columns("id", "title", "status", "updated_at").
    OrderBy("updated_at", "desc").
    Budget(10_000, 50<<20),
)
```

The Local Replica stores normalized authoritative entities, optimistic
overlays, Live Query ID memberships, pending commands, and the applied server
revision. A `replica.transaction` updates all affected entities and memberships
before subscribers are notified once.

Web persistence uses IndexedDB. Expo/mobile uses `@gonvex/expo-sqlite`, which
updates normalized entity/query tables and the cursor in one SQLite
transaction.

Collections explicitly report `complete` or `partial`. Offline filters over a
partial collection are labeled as cached partial results.
