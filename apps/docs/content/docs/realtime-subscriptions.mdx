---
title: Realtime delivery
description: Transaction streams, Live Queries, and Replica Collections.
---

Gonvex has two continuous read-delivery modes:

- Replica Collections deliver bounded entity snapshots plus committed changes.
- Live Queries deliver exact server windows plus membership/order deltas.

Both feed the same normalized Local Replica. A server transaction is persisted
and applied atomically before React or signal subscribers are notified.

Normal application code uses `useLiveQuery` and `useReplicaCollection`; it does
not construct WebSocket messages or own reconnect/subscription state.
