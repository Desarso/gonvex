---
title: Live Queries
description: Exact indexed server windows over datasets too large to replicate.
---

Live Queries maintain exact PostgreSQL-computed result windows. Registration
requires a structured plan:

```go
app.LiveQuery("tasks.grid", TasksGrid, gonvex.LivePlan(
  gonvex.LiveTable("tasks").
    Filter(gonvex.Eq("workspace_id", gonvex.Arg("workspaceId"))).
    SearchArg("search", "title", "description").
    SortArgs("sort", "direction", "deadline", "asc", "deadline", "created_at").
    WindowArgs("offset", "limit", 100, 150),
))
```

Gonvex derives tables, columns, filters, ordering fields, and window behavior
from this plan. Safe entity-only changes patch directly. Filter/order/window
changes rerun one canonical SQL query, diff IDs, and fan out a small delta.

Portable operators use the same expression tree offline against cached rows.
Postgres-specific capabilities must be marked online-only.
